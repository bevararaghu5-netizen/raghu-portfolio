# Bevara Raghunadh – Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript. This version uses a clean light professional template and lists the Go Furniture CI/CD implementation only once.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Deploy with Netlify
1. Create a new GitHub repository, for example `raghu-portfolio`.
2. Upload these files to the repository root (`index.html`, `style.css`, `script.js`, `README.md`).
3. In Netlify, choose **Add new site → Import an existing project**.
4. Connect GitHub and select `raghu-portfolio`.
5. Keep the build command empty and publish directory as `.` (the repository root).
6. Select **Deploy**.

## Before publishing
- Add your resume PDF and link it from the hero or contact section if you want it downloadable.
- Add your course certificate image/PDF if you want to display it directly.
- Review every project description and link to ensure it matches the current repository content.
- You can add a professional photo later; the current design intentionally works without one.

## Files
- `index.html` – page content
- `style.css` – responsive dark theme
- `script.js` – mobile navigation and current year
